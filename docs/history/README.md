# Build history

These are **FeatherSpec's own** build briefs — how this template was built and migrated. They
are kept for contributors, not as format examples.

Two warnings if you read them:

- They predate the plan mandate, so neither has a `.plan.md`, `AC-` ids or a traceability
  table. A spec produced by `/sdd-specify` today looks different, and better.
- `0002` certified a layout that a later commit reversed: `.claude/skills/` no longer exists,
  `.claude/commands/` and `.github/prompts/` do. Its ticked Definition-of-Done items are a
  record of the state at merge time, not of the repository today. That is exactly the failure
  this template now guards against — a ticked box is not an oracle.

**If you cloned FeatherSpec to start a project, delete this folder.** It is our history, not
yours. `.specs/` is deliberately empty so your first spec is `0001`.
